# ChordGun Expanded

A personal extension of [ChordGun](https://github.com/benjohnson2001/ChordGun) for **REAPER**, adding automatic voice leading and additional voicing options to the original chord-writing workflow.

## Added features

- **Voice-leading modes:**
  - **Off** — standard behavior.
  - **Closest tones** — choose nearby chord tones relative to the preceding voicing.
  - **Closest inversion** — choose a nearby inversion of the next chord.
- **Voicing modes:** Close, Drop-2, and Wide + low root.
- **MIDI-aware reference:** use the previous MIDI onset as the voice-leading reference, with preview fallback when needed.
- **Workflow integration:** selected-chord handling, interface controls and dedicated REAPER actions for the added features.

Built around practical composition needs: smoother movement between chords and more control over how those chords are voiced.
